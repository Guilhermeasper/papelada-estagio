# Papelada Estágio

Papelada Estágio is an application built with React, TypeScript, and Vite designed to manage and streamline internship paperwork and documentation.

This project is open for collaboration and we welcome developers to join and improve it. We prioritize a clean, maintainable, and readable codebase, making use of industry standard best practices for linting, formatting, and structural organization.

## Quick Start

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation
Clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/papelada-estagio.git
cd papelada-estagio
npm install
```

### Development Server
Run the local development server:

```bash
npm run dev
```

The app will be available at [http://localhost:5173](http://localhost:5173) (or the port specified by Vite).

## Available Scripts

- `npm run dev` - Starts the Vite development server.
- `npm run build` - Builds the application for production.
- `npm run lint` - Runs ESLint across the codebase.
- `npm run prettier` - Formats the codebase with Prettier.
- `npm run preview` - Locally previews the production build.
